# Owner-supplied photos

Drop photographs in this folder **only** if one of these is true:

1. You took the photo yourself, or
2. You have written permission from the copyright holder to use it on this
   site.

## Do not

- Do **not** save photos scraped or downloaded from countbinface.com, news
  sites, social media, or image search. They are copyrighted and using them
  here would be an infringement, regardless of how easy they are to find.
- Do **not** hotlink to images hosted elsewhere.

## The correct way to get an official press photo

Count Binface's official site (https://countbinface.com) has a contact page.
Email the Binface team to request permission to use an official press photo on
this campaign site, and keep the written permission on file. Only add the image
here once that permission is granted.

## Wikimedia Commons alternative

CC-licensed images (for example `File:Count Binface.jpg`, CC BY-SA 4.0) may be
used **with attribution**. If you add one, download it into `src/assets/` and
record the author, source URL, licence and any modifications in the image
credits on `/legal`. CC BY-SA attribution is mandatory and must not imply the
licensor endorses this site.

Every image on the site needs descriptive alt text, explicit width/height, and
an AVIF/WebP version. The site's mascot and artwork are original SVGs and need
no third-party licensing.
